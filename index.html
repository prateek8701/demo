What is a Database & Application Data Flow

📁 vs 🗄️

Why Applications Need Databases

  • Persistence: Data remains intact when the app closes or crashes.
  • ACID Guarantees: Prevents corrupted or partial transactions.
  • Instant Lookups: B-Tree indexes search millions of rows in milliseconds.
  • Concurrency: Thousands of users can read and write simultaneously.

schema.sql 
CREATE TABLE EMPLOYEE (
  empId INTEGER PRIMARY KEY,
  name  TEXT    NOT NULL,
  dept  TEXT    NOT NULL
);
Primary Key Rule

empId uniquely distinguishes each row and builds an automatic search index. No duplicate or null IDs are permitted.
